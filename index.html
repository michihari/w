執筆帖 — 初期設定

このアプリを使うには、Supabase プロジェクトの接続情報を設定してください。

  1. supabase.com で無料プロジェクトを作成
  2. SQL Editor で、同梱の setup.sql（テーブル作成スクリプト）を実行
  3. Authentication → Providers → Email を有効化（確認メールは任意）
  4. Project Settings → API から Project URL と anon public key を取得
  5. この HTML ファイルをテキストエディタで開き、先頭付近の 
    const SUPABASE_URL  = "ここにProject URL";
const SUPABASE_ANON = "ここにanon key";
    を書き換えて保存

設定後にこのページを再読み込みすると、ログイン画面が表示されます。
