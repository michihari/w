執筆帖 — 初期設定

Supabase プロジェクトの接続情報を設定してください。

  1. supabase.com でプロジェクトを作成
  2. SQL Editor で、同梱の setup.sql を実行
  3. Authentication → Providers → Email を有効化
  4. Project Settings → API から Project URL と公開キーを取得
  5. この HTML ファイルの先頭付近を書き換えて保存 
    const SUPABASE_URL  = "ここにProject URL";
const SUPABASE_ANON = "ここに公開キー";
